# UI skills

Third-party agent skills from https://www.ui-skills.com (registry: github.com/ibelick/ui-skills, MIT),
fetched 2026-11-20 with `npx ui-skills get <name>` and reviewed before adding.
Authors: ibelick (baseline-ui, improve-ui, fixing-accessibility, fixing-motion-performance),
dammyjay93 (interface-design), anthropics (frontend-design), vercel-labs (web-design-guidelines).

Project rules in CLAUDE.md always win over these skills (e.g. colour tokens, WCAG 2.1 AA,
no hard-coded UI text, `<Table>` for records, `moneyFormatter()`, `npm run ui:audit`).
